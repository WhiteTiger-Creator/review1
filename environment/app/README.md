# Wind Tunnel Aerodynamic Coefficient Validator (WTAC)

Lab calibration CLI for pressure-integrated lift/drag/moment coefficients,
balance cross-checks, tare calibration statistics, and uncertainty budgets.

```bash
make build
wtac-validate eval --campaign-dir /app/fixtures/campaigns/NACA0012-A4 --work-dir /tmp/out
```

Contracts live under `/app/docs/`.
