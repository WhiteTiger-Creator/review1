Custody token charter

Closed glyphs are selectors for observable custody behavior, not digests,
passwords, or values derived from key names. The schema defines membership,
the binding register defines behavior, and the Canon defines which behavior is
faithful to release doctrine. No arithmetic, hashing, truncation, or staged
restatement produces a selector. Companion selectors and the dual mesh root
are authorization evidence in their own right; no primary selector overrides
a missing companion. Informal desk notes have no charter authority.
