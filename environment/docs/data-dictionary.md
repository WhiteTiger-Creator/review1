A table whose name ends in p holds the held out examples paired with the table
of the same name. Tables named plain carry the ordinary case, where every pair
score is distinct and one class wins each prediction outright. The remaining
tables are deliberately awkward: pairs that score exactly alike so the structure
depends on how the tie is settled, and examples whose class scores come out
exactly equal. The single class table exists so a degenerate fit can be refused.
