# Four-dimensional convex-geometry face-incidence census

Input is N followed by N distinct integer points in R4. Use 5 <= N <= 16 and coordinate magnitude at most 10000. The point set may be full-dimensional or may lie in a lower-dimensional affine subspace. Some full-dimensional instances may contain interior points, and a convex-hull facet may contain more than four input points.

For every four-point affine-independent subset, evaluate the exact four-dimensional determinant against every input point. It is an exposing carrier when all points lie on one side of its affine hyperplane and at least one determinant is nonzero. An all-zero orientation vector is affine-degenerate and must not be recorded as a facet. Merge all exposing carriers having the same complete set of coplanar input IDs. Every merged set is a facet and contains at least four IDs. If no merged facets exist, the boundary census is empty.

Write HULL h followed by the increasing one-based IDs that occur in at least one merged facet. Then write FACETS f and one line FACET k i1 ... ik for each merged facet. Sort facet lines lexicographically by their increasing ID lists. For a lower-dimensional configuration with no merged facets, write HULL 0 and FACETS 0.

After the facet rows, write `FACET_HASH H`. Start H at 17 and scan facets in output order, appending k and then every one-based facet ID. Then write `TRIPLE_FACE_HASH T`. Start T at 31 and scan every increasing triple of hull vertex IDs in lexicographic order; append the three one-based IDs and the number of output facets that contain all three vertices.

Then write `NORMAL_HASH U`. For each facet in output order, choose the unique primitive integer boundary equation `a0*x0 + a1*x1 + a2*x2 + a3*x3 + b = 0` whose coefficients have gcd one, which vanishes on every input ID listed in that facet, and whose values on all input points are nonnegative. The equation may be obtained from any affine-independent four-ID subset of the complete facet; the first four listed IDs are not guaranteed to be affine-independent. Start U at 43 and scan each facet by appending k, its one-based facet IDs, and the five signed coefficients `a0 a1 a2 a3 b`.

Then write `PAIR_NORMAL_HASH P`. Start P at 83 and scan every unordered pair of output facets in output order. If the two facets intersect in fewer than two input IDs, skip the pair. Otherwise append the one-based output positions of the two facet rows, the intersection size, the one-based IDs in the intersection, the five signed primitive coefficients of the left facet, and then the five signed primitive coefficients of the right facet.

Then write `INTERSECTION_HASH V`. For every unordered pair of output facets, intersect their ID sets. Keep each distinct intersection of size at least two, sort these intersections lexicographically by increasing ID list, and for each one append its size, its one-based IDs, and the number of output facets that contain every ID in that intersection. Start V at 59.

Finally write `CARRIER_SIGN_HASH W`. Start W at 71 and scan every increasing four-tuple of input IDs. Compute its integer hyperplane equation. Skip the tuple if the equation is all zero or if all input points evaluate to zero on that hyperplane. Otherwise orient the sign vector so the first nonzero evaluation in input order is positive. Append the four one-based tuple IDs, then append one sign code for every input point in input order: 0 for negative, 1 for zero, and 2 for positive.

Finally write `VERTEX_FIGURE_HASH X`. Start X at 97. For each hull vertex ID in increasing order, append that one-based ID, the number of output facets containing it, and the one-based output positions of those facets. Then scan every unordered pair of those incident output positions, append the two positions, the size of the two facets' common ID set, and the one-based IDs in that common set.

Finally write `FACET_TRIPLE_HASH Y`. Start Y at 109. Scan every unordered triple of output facets in output order. Intersect their ID sets; skip the triple when the intersection is empty. Otherwise append the three one-based facet positions, the intersection size, the one-based IDs in the intersection, and the number of output facets that contain every ID in that intersection.

Finally write `FACET_QUAD_HASH Z`. Start Z at 127. Scan every unordered quadruple of output facets in output order. Intersect their ID sets; skip the quadruple when the intersection is empty. Otherwise append the four one-based facet positions, the intersection size, the one-based IDs in the intersection, and the number of output facets that contain every ID in that intersection.

Then write `FACE_LATTICE_HASH L`. Let the complete nonempty face family consist of the full `HULL` ID set and every distinct nonempty intersection of one or more output facets. The affine dimension of a face is the rank of its coordinate-difference vectors over the rationals. Sort faces first by increasing affine dimension and then lexicographically by their increasing ID lists. Start L at 149; for each sorted face append its dimension, its size, its one-based IDs, and the number of output facets that contain all of its IDs.

Finally write `FLAG_HASH G`. Start G at 163. Scan all quadruples of sorted-face positions `(p0,p1,p2,p3)` such that their dimensions are respectively 0, 1, 2, and 3 and each face's ID set is a strict subset of the next. Sort these quadruples lexicographically and append their four one-based positions.

Then write `FACET_CARRIER_HASH A`. Start A at 181. For each facet in output order append its one-based facet position, its size and IDs, and its five canonical primitive coefficients. Next scan every increasing four-ID subset of that facet. Append the four one-based IDs. If its five determinant cofactors are all zero, append 0. Otherwise divide the cofactors by their coefficient gcd, orient the primitive tuple to equal the facet's canonical equation, append 1, and append the resulting five coefficients.

Then write `FACE_NORMAL_HASH B`. Start B at 191. For each face in the sorted complete face family, append its one-based face position, affine dimension, size, and IDs. Form the increasing list of output-facet positions whose ID sets contain the face. Append that list's size and positions, then append the five canonical coefficients of each listed facet in the same order.

Then write `NORMAL_GRAM_HASH C`. Start C at 193. Scan every unordered pair of output facets whose ID-set intersection is nonempty. Let r be the one-based position of that exact intersection in the sorted complete face family. For spatial normal vectors `u=(a0,a1,a2,a3)` and `v=(c0,c1,c2,c3)`, append the two facet positions, r, the intersection size and IDs, `u.u`, `v.v`, `u.v`, and `(u.u)(v.v)-(u.v)^2`.

Finally write `FLAG_NORMAL_HASH D`. Start D at 197 and scan the same maximal flags in the same order as `FLAG_HASH`. The dimension-three face is an output facet. Append the four one-based face positions, that facet's one-based output position and five canonical coefficients, then append the numbers of output facets containing the dimension-zero, dimension-one, and dimension-two faces, respectively.

All hashes use modulus 1000000007 and base 1000003: appending x means `H = (H * 1000003 + x) mod 1000000007`, reducing every signed or oversized integer modulo 1000000007 before appending. Empty censuses therefore keep the initial hash values: FACET_HASH 17, TRIPLE_FACE_HASH 31, NORMAL_HASH 43, PAIR_NORMAL_HASH 83, INTERSECTION_HASH 59, CARRIER_SIGN_HASH 71, VERTEX_FIGURE_HASH 97, FACET_TRIPLE_HASH 109, FACET_QUAD_HASH 127, FACE_LATTICE_HASH 149, FLAG_HASH 163, FACET_CARRIER_HASH 181, FACE_NORMAL_HASH 191, NORMAL_GRAM_HASH 193, and FLAG_NORMAL_HASH 197. End with one newline and no other output.
