# Qualitycast artifact format

JSON and JSONL field definitions for forge outputs:

- Bout tensors: see /app/docs/bout-tensor.md (session_features.jsonl)
- Milliwights: see /app/docs/l2-milliwight.md (ridge_weights.json)
- Eval ledger: see /app/docs/quality-ledger.md (eval_ledger.json)
- Digests: see /app/docs/tensor-digest.md (feature_digest.json)

All schemas use the cdnqual.*.v1 identifiers documented in those contracts.
