INPUT

Standard input is a sequence of ASCII lines. Every line, including the last,
ends with a single newline byte. A line holds at most 64 characters before the
newline. Fields are separated by single space characters. A numeric field is
unsigned decimal with no sign and no leading plus, written as 1 to 10 decimal
digits.

The first line is

  S <tick>            <tick> in 0..4294967295

and it sets the clock. The clock is a 32 bit counter that wraps to 0 after
4294967295.

Every later line is one of

  A <id> <deadline>   <id> in 0..65535, <deadline> in 0..4294967295
  C <id>              <id> in 0..65535
  T <n>               <n> in 1..65535

A arms a timer under that id with that deadline, C cancels the timer held under
that id, and T advances the clock by n ticks.

Arming an id that is already armed, cancelling an id that is not armed,
cancelling an id that has already come due, and arming a deadline that the
clock is not ahead of are all accepted operations rather than errors. An
operation being accepted does not mean it takes effect: arming an id that is
already armed is accepted and changes nothing, and which other operations the
executable absorbs in the same way is settled by the executable alone.

At most 20000 lines follow the S line. At most 8192 timers are armed at any one
moment. The sum of n over every T line in the input is at most 33554432.

OUTPUT

Each T line produces exactly two lines on standard output:

  F <tick> <id> <id> ...
  E <count>

<tick> is the clock value after the advance. The ids listed are the timers that
came due during that advance, given in the order they came due. A T line during
which nothing came due still produces its F line, holding the tick and no ids.
<count> is the number of timers still armed once the advance is finished.

After the last input line one further line is written:

  D <digest>

where <digest> is exactly eight lowercase hexadecimal digits.

Nothing else is written to standard output, nothing is written to standard
error, and the exit status is 0.

ERRORS

The first line that fails a check ends the run. Whatever was already written to
standard output stays there, then the single line

  ERR <token>

is written and the exit status is 1. No D line is written. The checks are
applied to a line in this order, and the token names the first check that
fails:

  syntax    the line is not one of the four forms above. This covers an
            unrecognised first field, a first field longer than one character,
            the wrong number of fields, a numeric field that is not 1 to 10
            decimal digits, a line longer than 64 characters, a final line with
            no terminating newline, a blank line, an S line that is not the
            first line, and any line that appears before the S line.

  range     every field is well formed but one of them lies outside the range
            given for it above.

  ops       the line would be the 20001st line after the S line.

  capacity  an A line arriving while 8192 timers are already armed.

  budget    a T line whose n would carry the running total of advanced ticks
            past 33554432.

An input holding no S line at all reports syntax.
