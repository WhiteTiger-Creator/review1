Sheet and observation schema (sch_n)

Driver bash path /app/environment/drive_k4.sh builds the local kit and writes four paths under /app/output named obs_primary.json, obs_hold.json, rights_map.json, and transparency.txt.

Optional argv defaults are --root /app/environment and --out /app/output. That optional form uses exactly four argument tokens after the script name. The --help flag prints a short usage line and exits 0. Exit code 0 on success. Nonzero on build or emit failure. Unknown flags exit 2.

Observation JSON top-level object members are root, rows, band_digest, q_digest, gen, and eval_fp. root is a string equal to primary or hold. rows is an array of channel objects. Each channel object has members sid (string id), bands (array of float64 folded bands), cls (array of int ladder values), q (array of float64 fatigue vector), and fld (int 0 or 1 for the alert-flood mark from pol_n). band_digest and q_digest are lowercase hex strings. gen is the integer lineage generation from seal_n. eval_fp is the 8-hex evaluation fingerprint from seal_n.

Inference pack JSON under fixtures/primary and fixtures/hold may include integer fields mode and gen. mode >= 1 marks campaign replay. gen selects which journal record may seed the fold cache and budget prior (see pol_n). When gen is omitted it is treated as 0.

Campaign journal files live at /app/environment/var/journal/<sid>.json with object members gen (int), bands (float64 array), cls (int array), q (float64 array), and eval_fp (8-hex string). The driver may create or replace those files during a run. They are intermediate state, not the scored deliverables.

Eval ledger lines live at /app/run/psr_ledger.jsonl. Each line is a JSON object with sid, root, bands, cls, q, fld, gen, and eval_fp. Recover rebuild rules live in seal_n.

Rights mapping sheet JSON rights_map.json members are version, grants, digests, qdig, neg, fld_any, gen, and eval_fp. version is the fixed five-character token that starts with k4 and ends with 1 with a hyphen between (same token named in the instruction). grants is a list of objects with sid and acc where acc is full or limited, sorted by sid. full means unrestricted stream use; limited is the degraded grant. digests maps primary and hold onto band_digest values. qdig maps primary and hold onto q_digest values. neg is a list of strings as defined in pol_n (the non-goals list). fld_any is int 0 or 1, and is 1 when any observation row in either root has fld equal to 1. gen and eval_fp must match the COMMIT seal.

Transparency file is plain text with one ng token per line matching neg order. No trailing blank line is required; a single trailing newline is allowed.
