Sheet and observation schema (sch_n)

Driver bash path /app/environment/drive_k4.sh builds the local kit and writes four paths under /app/output named obs_primary.json, obs_hold.json, rights_map.json, and transparency.txt.

Optional argv defaults are --root /app/environment and --out /app/output. That optional form uses exactly four argument tokens after the script name. The --help flag prints a short usage line and exits 0. Exit code 0 on success. Nonzero on build or emit failure. Unknown flags exit 2.

Observation JSON top-level object members are root, rows, band_digest, and q_digest. root is a string equal to primary or hold. rows is an array of channel objects. Each channel object has members sid (string id), bands (array of float64 folded bands), cls (array of int ladder values), q (array of float64 fatigue vector), and fld (int 0 or 1 for the alert-flood mark from pol_n). band_digest and q_digest are lowercase hex strings.

Corpus pack JSON under corp/primary and corp/hold may include integer fields mode and gen. mode >= 1 marks campaign replay. gen selects which journal record may seed the fold cache and budget prior (see pol_n). When gen is omitted it is treated as 0.

Campaign journal files live at /app/environment/var/journal/<sid>.json with object members gen (int), bands (float64 array), cls (int array), and q (float64 array). The driver may create or replace those files during a run. They are intermediate state, not the scored deliverables.

Rights mapping sheet JSON rights_map.json members are version, grants, digests, qdig, neg, and fld_any. version is the fixed five-character token that starts with k4 and ends with 1 with a hyphen between (same token named in the instruction). grants is a list of objects with sid and acc where acc is full or limited, sorted by sid. full means unrestricted stream use; limited is the degraded grant. digests maps primary and hold onto band_digest values. qdig maps primary and hold onto q_digest values. neg is a list of strings as defined in pol_n (the non-goals list). fld_any is int 0 or 1, and is 1 when any observation row in either root has fld equal to 1.

Transparency file is plain text with one ng token per line matching neg order. No trailing blank line is required; a single trailing newline is allowed.
