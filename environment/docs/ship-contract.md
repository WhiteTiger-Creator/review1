Public field names used by the hostctl-export oneshot include event selected_id note_text sha_prefix pack_label case_id cases entries evidence_tier rows supersedes ship_complete complete generation book_stamp stage_path.

Operator flags include --book --langpack --from-unit --pack --snaps --out --fresh. Digests use sha_prefix length 12. Equal-tier ties resolve to supersede-chain roots then lexicographic minimum id. Incomplete journals must not promote leftover staged bodies; the oneshot must re-select and re-emit under the active exclbook. A completed journal is stale when book_stamp or pack_label no longer matches the active book or language pack. A non-stale completed journal may reuse the prior digest only when the staged body still obeys the ASCII decimal rule; generation holds for that validated reuse and otherwise increases on re-select or re-emit. The ship appends reconcile_trace.jsonl across runs. Refresh installed host binaries with make -C /app/environment PREFIX=/app install. Property checks use /app/bin/check_bin --pack <label> with label C or de_DE. Full procedures live in ship-contract.rst beside this file.
