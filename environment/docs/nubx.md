# Nubx privilege-audit contract

## Commands

Synthesize the authorization transcript:

```
/app/environment/tools/drvx synth --annex /app/environment/corpus/annex29.wav --out /app/output/protocol_transcript.json
```

Certify independent privilege replay:

```
/app/environment/tools/drvx certify --transcript /app/output/protocol_transcript.json --report /app/output/replay_certificate.json
```

After enforcement changes, rebuild from `/app/environment`:

```
cd /app/environment && go build -o /app/environment/tools/drvx ./cmd/drvx
cp -f /app/environment/tools/drvx /app/bin/drvx
```

## protocol_transcript.json

Schema string `nubx-transcript-v1`.

`rows` is an array, one object per lane listed in `/app/environment/data/suite_meta.json`
field `lanes`, in that order. Each row includes `lane`, `slab`, `knit_hex`,
`pair_hex`, `esc_hits`, `win_count`, `windows` (`{t0,t1,tx}` ordered by `t0`),
and `deltas`.

`escalation_total` is the sum of per-row `esc_hits` and must be `0` for the
closed fixture algebra.

`suite_digest` is lowercase hex SHA-256 over `lane:knit:pair:esc` joined with
`|` in lane order.

Structural pins (window cardinalities, held-out tx labels) live under
`/app/environment/corpus/seal/`. Digests are regenerated by a correct pipeline
rather than copied from seals.

## replay_certificate.json

Schema string `nubx-replay-v1` with `band`, `digest`, `replay_digest`,
`observations`, and `in_band`.

Certify must rebuild observations from the transcript file alone after a fresh
process start. Partial text under `/app/output/scratch`, residual files under
`/app/output/.nubx_latch`, and dashboard caches under `/app/output/.nubx_shadow`
are not authoritative clock or fold sources. Local dashboard witnesses that
report green are not authoritative for privilege reliability.

## Canonical JSON digests

`knit_hex`, `pair_hex`, and certificate digests hash UTF-8 bytes of compact JSON
with object keys sorted recursively at every object level (no insignificant
whitespace). Numbers are ordinary JSON numbers. The hash function is SHA-256;
operators may verify with Python `hashlib.sha256` over the canonical UTF-8 bytes
and lowercase hex encoding.

## Idempotence and restart

Running synth twice with the same annex must yield identical `suite_digest` and
per-row `knit_hex` values. Certify must not rewrite the transcript artifact.
After a process restart, certify must not diverge because of residual latch,
scratch, or shadow files left by a prior synth.
