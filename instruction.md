Moonrail is a small solitaire board game about riding a lunar rail loop, collecting emblems, and stopping before the board overheats. I need the local match referee at `/app/bin/moonrail-route` to score saved Moonrail rounds and write the best legal stopped journey as JSON.

Run it as `node /app/bin/moonrail-route --input /app/task_file/samples/public_match.json --output /app/out/result.json`. The match format and all Moonrail scoring rules are in `/app/task_file/moonrail_rules.md`; that rules sheet is the public game reference. The output file must be UTF-8 JSON with exactly these fields: `score` integer or null, `path` array of site id strings including the start site, `claimed` array of claimed site id strings in visit order, `contracts` array of completed contract id strings, `final_energy` integer, and `final_heat` integer. Exact values and ordering are graded.

Use `score: null` only when no legal move can be taken from round 1, stopping at round 0 scores 0, and no contract is completed by that stopped board. In that case write `path: [start]`, empty `claimed` and `contracts`, and the unchanged starting energy and heat. Already visited sites still appear in `path` when revisited, and a site that was visited but not claimed because it was sealed or blocked may be claimed on a later arrival if its gates are then satisfied. Tie-breaks compare the complete final result in the order stated in the rules file, not just the next move.
