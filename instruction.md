# Our players cannot find a match, the in game server browser is empty
The master server behind Hypersomnia's browse servers screen fell over mid session and came back empty, so nobody can find a match. All we kept is the journal of datagrams its command socket received.
Write `/app/mslist` and run it as `/app/mslist <journal> <config> <out-dir>`. It replays a journal and rebuilds the browser listing the master server would have been serving when the recording stopped: which game servers were still registered, how long each had been hosting and how many heartbeats it was credited with, the arena and game mode it ran and whether that arena is one we publish, both teams with their players and scores, and whether it is one of our ranked machines or a community box. The ban list and entry timeout named in the config both apply, and a server that asked to stay off the browser stays off. Leave `server_list.json` and `snapshot.bin` in the output directory, creating it if missing. A journal it cannot make sense of has to fail loudly rather than half write a report.
The recording is `/app/journal/session14.cap`, the settings `/app/msconfig.json`, both output formats are in `/app/docs`, and `/app/hypersomnia` is the game. Leave the run over that recording in `/app/out`.
