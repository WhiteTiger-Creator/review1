# Quantization drift certification for static computation graphs

Model compression reviewers load static graph packs and quant manifests, propagate feature intervals through the interval store, seal layer-order digests, and publish an analytical drift certification ledger to /app/output when candidate INT8 weight packs keep layerwise envelopes inside contractual drift ceilings versus a frozen FP32 graph. Complete qbound-analyzer for static interval propagation (never runtime inference) that publishes drift_certification_report.json.

The baseline image already builds qbound-analyzer. Extend the module tree documented in /app/docs/ml-bound-product-scope.md and /app/docs/ml-interval-certification-workflow.md so the CLI can load graph packs, propagate intervals, write layer-order digests, and publish overrun rows. Subcommands and stderr markers are defined in /app/docs/qdrift-cli-surface.md. Interval algebra, dtype widening, affine error budgets, graph JSON, workspace snapshots, walk-order seals, epoch tightening, and report fields are split across /app/docs/interval-walk-rules.md, /app/docs/quant-format-specs.md, /app/docs/quant-dtype-matrix.md, /app/docs/static-graph-schema.md, /app/docs/bound-workspace-snapshot.md, /app/docs/walk-witness-contract.md, /app/docs/certification-epoch-policy.md, /app/docs/drift-report-contract.md, and /app/docs/ml-bound-product-scope.md.

Certification trials assume qbound-analyzer was built with /app/scripts/rebuild-qbound-analyzer.sh. The tool reasons only about symmetric INT8 affine layers and ReLU nodes declared in static graph JSON, not general ONNX execution.

Bundled graph packs live under /app/fixtures/static-graphs, variant overrides under /app/fixtures/quant-variants, and drift ceilings under /app/fixtures/drift-scenarios. linear-clean with v-int8-tight and scenario-tight must certify with zero overruns. linear-mixed with v-int8-loose and scenario-standard must flag aff2 and output when measured_drift exceeds 0.08. relu1 snapshots must keep nonnegative ref.lo and quant.lo. Digest seal rules are defined in /app/docs/drift-report-contract.md. Agents must rebuild before publish trials.
