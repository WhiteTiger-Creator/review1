Under /app/environment a small C++ project reads a symmetric positive-definite matrix A from a case file and reports its principal square root together with the trace of the iteration that produces it. Each file matching /app/environment/data/case_*.txt holds one case: the order n followed by the packed lower triangle of A, as described in /app/environment/docs/storage_format.md. Every A is positive definite, and n ranges from 2 to 10.

Given a case file and an output path, the program reports two n by n matrices X and Z and a scale trace. X is the symmetric positive-definite matrix with X times X equal to A, and Z is the symmetric positive-definite inverse with X times Z equal to the identity. X and Z are fixed as the final iterates of the determinantally scaled coupled iteration specified in /app/environment/docs/problem_statement.md, and the per-step scale factor of that iteration must also be reported. The exact recurrence, the fixed step count, the output schema, and the acceptance tolerances live in problem_statement.md, output_format.md, and result_contract.md. The scale trace is graded, not diagnostic. The case matrices span well conditioned to very ill conditioned and a wide range of magnitudes, and the report must meet the tolerances across that whole range.

Do not link against or call LAPACK, Eigen, GSL, Armadillo, BLAS, or MKL; compute everything under /app/environment/src and /app/environment/include. Implement the function declared in /app/environment/include/matsqrt.hpp by editing /app/environment/src/matsqrt_impl.cpp; the other sources and headers need no changes. Build with /app/environment/build.sh, then run for example ./build/matsqrt data/case_spd_n5_c6.txt /tmp/out.txt.
