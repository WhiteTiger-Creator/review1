NOC wall panels for an old campus arrived as a bundle under /app/panel. Complete the incomplete Perl modules and dispatcher under /app/lamps so that `make -C /app dispatch PANEL=/app/panel OUT=/app/out` publishes the board. Sound boards leave `/app/out/beacon.queue` and `/app/out/runner.fold` and exit 0; unsafe boards leave the output empty (keep `.keep`) and exit non-zero. Every run must scrub the resolved OUT directory so only allowed entries remain (see `/app/contract/01_invoke.md`).

Normative behavior for every board is defined by `/app/PANEL_NOTES.md` and the files it indexes under `/app/contract/` (01 through 05). The live `/app/panel` bundle is only one sound board; other boards share the same contract. The dispatcher implementation must remain the Perl sources under `/app/lamps` (the make target invokes that Perl entrypoint).
