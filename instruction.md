This is a refereeing task for a path-tile board game played on a square grid. Each cell can hold one path tile, and every tile carries four painted paths that join its eight edge-points in pairs under some rotation. Tokens stand on edge-points, each facing an empty cell it is about to enter. A move lays one tile, in a chosen rotation, on the empty cell the active token faces. The moment the tile is down, the flow fires. Every token facing the newly filled cell sets off at the same time, following the painted paths from tile to tile across the fixed board. A token keeps going until it reaches an edge-point facing an empty cell, where it stops, or until it runs off the rim, where it leaves play and is eliminated. Because the tokens move together, two that meet at one point collide and are both eliminated. The task is to settle one such move and report, for every token, either where it rests and which way it faces or that it left the board. The full rules of the game, the grid and edge-point numbering, the path pairing and rotations, and the exact input and output live at /app/docs/SPEC.md. The program reads one position per line from an input path and writes one result line per position to an output path, in order. It belongs in /app/src and plays offline. The examples in the rules do not cover every case.
